# Furniture Fullstack

E-commerce project — React 19 + Vite frontend, Express 5 + Prisma backend.

## Structure

- `frontend/` — React 19, Vite, TanStack Query, Zustand, shadcn/ui
- `backend/` — Express 5, TypeScript, Prisma, Redis/BullMQ

## Setup

```bash
# Backend
cd backend && npm install && npm run dev

# Frontend
cd frontend && npm install && npm run dev
```
